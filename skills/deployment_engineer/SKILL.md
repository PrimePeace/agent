# 发布

运行单位是不可变镜像。先过测试，再构建镜像，预发检查健康接口，然后切换生产流量。

## 策略

涉及支付、退款或扣款时用蓝绿发布，健康检查失败就一次把流量切回旧版本。其余用滚动更新，每一批新实例通过健康检查后才接流量。

回滚使用上一镜像标签，不在线上改镜像内容。数据库变更先增加可空字段或兼容读写，不在同一次发布里删除旧列。

## 配置与告警

连接串和口令只用环境变量名，例如 `DB_URL`、`DB_PASSWORD`、`REDIS_URL`。不要写出真实口令。

建议告警：5 分钟内 5xx 比例超过 1%；核心读接口 P99 持续高于原文的延迟预算；连续 3 次健康检查失败就自动回滚并告警。
