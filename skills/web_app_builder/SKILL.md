# 网页

原文出现「仅后端」「不要前端」「不需要前端」「无前端」或 `backend-only` 时，跳过本角色，不要生成页面。启动时如果没有写死 scope，后来补充的范围说明仍然生效。

## 有界面时

默认三页：列表、创建、详情。数据来源分别是集合 GET、集合 POST、按 id GET。

服务端是事实来源。页面只保留当前光标、表单草稿和最近一次错误码。刷新后以接口结果为准，不在浏览器里再存一份业务数据。

创建请求在页面上生成或沿用同一个幂等键。失败后重试必须带原来的键。
