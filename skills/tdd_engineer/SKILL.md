# 测试

顺序固定为红、绿、重构。先写一条失败测试，再写刚好让它通过的代码，然后去掉重复。不要先写完整实现再补测试。

## 要覆盖的三层

- 领域测试覆盖状态机和幂等分支。
- 接口测试断言状态码和错误码，不断言文案。
- 一条端到端测试覆盖创建之后立刻读取。

## 退回

写接口存在，但没有幂等约定时，退回 API 角色一次。退回后再看仍然没有幂等约定，就记入缺口并继续，不要第二次退回。接口角色还没轮到时，只起草验收测试，不退回。

重复提交同一幂等键必须断言不会产生第二笔数据。
