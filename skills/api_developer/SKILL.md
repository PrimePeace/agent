# 接口契约

一个业务名词对应一组资源。调用方和资源分开：用户可以创建订单时，资源是订单。

## 写操作

每个 POST 都要求 `Idempotency-Key`。同一个键、同一份正文，返回第一次的结果。同一个键、不同正文，返回 409。创建、登录、取消都算写操作。

列表用 limit 和 cursor。不要用可以被跳页放大的超大 offset。

## 读操作

按标识读取找不到资源时返回 404。需要登录的资源，未认证返回 401，响应体不含内部异常。

## 错误

沿用后端角色的错误码。没有后端产物时，也要区分参数错误、找不到、冲突、未认证和系统故障。状态码表达协议结果，错误码表达业务原因。
